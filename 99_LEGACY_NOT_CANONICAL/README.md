# Legacy / Non-Canonical Reference Notice

Older Jano Health architecture artifacts exist in the historical record that use broader assumptions such as:

- treating an event store as universal source of truth for all domains;
- treating microservices as mandatory;
- treating Fayda as an internal identity authority;
- using implementation-specific event catalogs or API/service maps;
- assigning security, infrastructure, or deployment responsibilities too broadly;
- creating very large platform capability inventories before logical ownership was clarified.

Those artifacts were not silently promoted into the current architecture.

They remain historical design material only and should be reconciled against the current canonical architecture before being used as implementation authority.

Anchor remains completely outside Jano Health.
