# Jano Health Architecture Documentation Control

This directory contains the control layer for the complete architecture pack. It is descriptive and administrative; authority remains in the approved canonical baseline and the governed approval process.

## Status model

- **Approved Architectural Baseline** — explicitly accepted authority.
- **Draft for Architectural Review** — substantive working artifact, not yet authority.
- **Deferred** — intentionally postponed.
- **Legacy / Not Canonical** — historical material that does not govern the current architecture.

## Canonical rule

The approved baseline is authoritative. Draft documents may describe candidates and detailed designs, but their presence does not grant approval.

## Boundary rules

No document in this pack may introduce Anchor into Jano Health, make Fayda the internal identity authority, make AI the clinical authority, make a specific cloud provider mandatory, or require microservices unless a future governed decision explicitly changes the architecture.
